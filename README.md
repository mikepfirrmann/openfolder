openfolder
==========

**This plugin is retired and no longer maintained.**

Sublime Text 4 does this natively. Right-click a folder in the side bar and
choose **Open Folder…**, or right-click a file and choose
**Open Containing Folder…**.

On Sublime Text 4 this plugin's side bar item doesn't work, because its
`open_folder` command has the same name as the built-in one
([#11](https://github.com/mikepfirrmann/openfolder/issues/11)). If you have it
installed, remove it with **Package Control: Remove Package** and use the
built-in menu items instead.
